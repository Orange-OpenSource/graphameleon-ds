# Processing

This folder holds scripts for complementary optional analysis of the Graphameleon dataset.

## Inter-arrival times

Run the [interarrival.py](./interarrival.py) script to compute inter-arrival times from Graphameleon traces.

```shell
# Install pre-requisites
pip3 install -r ./requirements.txt

# Run the script
python3 interarrival.py

# Browse results
cat GPL_normal_scenario.ttl.oct_interarrival.csv
```
